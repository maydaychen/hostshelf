# HostShelf 首版施工清单

创建时间：2026-10-23 22:10（北京时间）。授权：实现用户确认的首版计划；不启动 Goal，不连接真实服务器，不公开发布。初始基线：空目录、无 Git 仓库；本机 Xcode 27.1、Apple Silicon，签名身份和其他运行环境待验证。

## 结果与验收

- R1／AC1：索引用户、系统配置及 Include，支持软链接、通配符、重复别名、来源追溯、条件候选与错误诊断；隔离样本测试，不执行配置命令。
- R2／AC2、AC5：三栏窗口、搜索、详情、来源定位、菜单栏；明暗、空态、快捷键与窗口重开需实际检查。
- R3／AC2：分组、收藏、备注和最近发起时间只存应用目录；原配置内容不变；损坏文件保留。
- R4／AC3、AC4：变化合并刷新；静态 AppleScript 安全传参；权限允许／拒绝／恢复、新窗口保护与真实连接分别留证。
- R5／AC6、AC7：macOS 14+ 的 arm64 和 x86_64 两份单架构产物；签名、公证、装订、Gatekeeper、安装和对应硬件运行分别验证。

## 任务、接口与委派

所有协作者先读 AGENTS；共享工作区，不撤销他人修改。只能改各自所有权文件；需要共享接口变化先交接主 Agent。禁止访问私钥、执行 SSH、改用户配置、提交或外部发布。

### T1：主 Agent／工程与交付

拥有项目规则、公共模型、XcodeGen／SwiftPM 清单、构建运行打包脚本、项目文档和 Git。先建立公共模型及下述接口，再派发 T2–T4。创建测试和 ARM／Intel 入口，按检查点更新实际证据并提交。所有调用从项目根执行，生成物放 .tmp，交付物放 dist。签名身份缺失时交付清晰标识的本地试用产物，正式公证保持未完成。

### T2：索引 worker

拥有 `Sources/HostShelfCore/SSHConfigIndexer.swift`、必要 lexer 辅助文件及 `Tests/HostShelfCoreTests/SSHConfigIndexerTests.swift`。输入 roots（默认用户＋系统）、homeDirectory、environment，输出 SSHIndexSnapshot。公共模型在 Models.swift，由主 Agent 维护；scan 不访问 IdentityFile、不执行子进程。Include 在出现位置展开，用户相对路径基于用户 .ssh，系统相对路径基于 /etc/ssh，glob 按字典序；当前递归链识别循环，同文件不同包含位置不丢失。解析引号、注释、key=value；条件上下文标记候选，不求值；动态 tokens 未解析就诊断。交付实现和有意义失败／边界测试；运行 swift test 的自身过滤范围。

### T3：持久化与连接基础 worker

拥有 `Sources/HostShelfCore/HostMetadataStore.swift`、`SSHCommand.swift`、对应测试，以及 `Sources/HostShelf/Services/TerminalLauncher.swift`、`ConfigurationWatcher.swift`。HostMetadataStore.init(fileURL:)，load() -> MetadataDocument，save(_:)；损坏后拒绝覆盖，原子写入。SSHCommand.connectionCommand(for:) throws -> String，验证别名并安全引用。TerminalLauncher @MainActor，launch(alias:) throws -> Void，NSAppleScript 固定 handler 以 AppleEvent 参数接收 alias，内部 `/usr/bin/ssh -- ` + quoted form；测试不执行生产 handler。ConfigurationWatcher @MainActor，start(directories:[String],onChange:@escaping @MainActor ()->Void)，stop()；使用 FSEvents 和事件合并，监听目录以捕获原子替换与 glob 新文件。不得在测试中实际启动终端或 SSH。交付测试、实现及未验证权限路径。

### T4：GUI worker

拥有 `Sources/HostShelf/App/`、`Views/`、`Stores/`。依赖公共模型及 T2/T3 的稳定接口，可先写 UI。AppStore 共享快照、元数据、搜索筛选、选择和提示；后台索引、主线程发布；启动、手动、重新激活及 watcher 触发刷新。元数据以 alias 关联，保留消失主机附加信息；分组自建，菜单栏收藏最多10／最近5。窗口管理保留 Dock 和菜单栏，已有窗口优先激活。细节遵循 DESIGN。交付可构建 UI 和手工验收入口；不得写其他 worker 文件或更改公共接口。

### T5：主 Agent 集成与独立验收

先核对实际 diff 和各 worker 测试，再集成构建；出现失败用 debugger 根因定位。release-verifier 只读检查最终架构、元数据、签名和交付差异，不代执行签名／上传／Git。真实 UI 用原生可访问性／截图核对，无法访问的权限或硬件明确缺口。代码、单测、运行、架构、安装、公证不混淆。

## 交付与恢复

源码、测试入口、运行入口、ARM／Intel 独立 DMG、使用说明和证据报告。发行凭据仅 Keychain／环境。任何失败不得通过改用户 SSH 配置、关闭安全检查或覆盖损坏数据绕过。未签名产物不能称正式发行；没有外部发布授权不上传公证或推送。
